# 意大利社保和中国"五险一金"有什么不同

> 意大利INPS和INAIL与中国五险一金对比：雇主养老缴费23.81%、员工9.19%，没有住房公积金，医疗由国家承担。中国企业如何做预算。


中国企业的HR和财务对"五险一金"非常熟悉：养老、医疗、失业、工伤、生育保险，加上住房公积金，单位和个人各缴一部分，比例和基数由各地规定。

意大利的社保体系结构不同。理解这些差异，才能正确估算一位意大利员工的成本。

## 意大利社保的结构

意大利员工的社保主要由两个机构管理：

- **INPS**（国家社会保障局）：负责养老、失业、病假、产假和家庭补贴；
- **INAIL**（国家工伤保险机构）：负责工伤和职业病。

和中国一样，雇主和员工各缴一部分。不同的是，各项费率是全国统一按行业和企业类别确定的，不像中国那样各省市不同。

## 最大的一项：养老保险

意大利的养老保险称为IVS，覆盖老年、残疾和遗属养老金。

- **雇主部分**：应税工资的23.81%；
- **员工部分**：应税工资的9.19%。

这两个数字来自意大利一家税务和工资资讯网站，属于二手来源，适合做规划参考。签发offer前，请让工资服务商确认适用于具体岗位和合同的费率，因为费率可能因雇主类别而不同。

雇主的23.81%是在税前工资之上的成本；员工的9.19%从税前工资中扣除，减少员工到手，不增加您的成本。

## 其他雇主缴费

除养老保险外，雇主还要缴纳：

- **失业保险（NASpI）**；
- **病假和产假**（并非所有员工类别都有）；
- **家庭补贴（CUAF）**；
- **TFR保障基金**；
- **工资保障基金**，视行业和企业规模而定；
- **INAIL工伤保险**，按岗位风险类别确定。

全部加起来，雇主社保约占税前工资的30%，视行业和岗位而定。

## 和五险一金逐项对比

| 中国 | 意大利 |
|---|---|
| 养老保险 | INPS养老（IVS），雇主23.81%，员工9.19% |
| 医疗保险 | 没有对应的雇主缴费：国家卫生服务由一般税收支付。部分CCNL有补充医疗基金 |
| 失业保险 | INPS失业保险（NASpI） |
| 工伤保险 | INAIL，仅雇主缴纳 |
| 生育保险 | INPS产假津贴，包含在雇主缴费中 |
| 住房公积金 | 没有 |
| — | TFR离职金：每年计提约6.91%，不是税，属于员工 |

几个要点：

**没有住房公积金。**这是很多中国财务第一次看到时会问的问题。意大利没有这项制度。

**医疗不是雇主成本。**意大利有国家卫生服务，所有居民都能使用，资金来自一般税收。雇主不需要为员工缴纳医疗保险，也不需要购买商业医疗保险。部分CCNL规定了补充医疗基金，费用计入用工成本。

**TFR是额外的一项。**它不属于社保，但同样是每月必须计提的成本。

## 缴费基数和上限

意大利的缴费基数一般是员工的应税工资，包括第13、14薪、提成和大部分奖金。

对于1996年起首次参保的员工，养老缴费有年度收入上限：2026年为€122,295，超出部分不再缴纳养老保险。另外，员工年收入超过€56,224的部分，员工费率加1个百分点。

对比中国：中国的社保缴费基数有当地社平工资的上下限。意大利只有上限，没有下限的概念（但有日最低应税收入的规定）。

## 预算常见的错误

**只按税前工资做预算。**雇主社保没有进计划。

**套用国内比例。**意大利雇主养老一项的比例就高于国内很多地区，总比例也不同。

**忘记它随工资变化。**调薪、提成、奖金都会带动社保增加。

**用错比较基础。**比较意大利员工和其他国家员工的成本，要比较雇主总成本，而不是税前工资。

## 怎么做预算

1. 从计划的税前工资开始；
2. 确定应税工资基数；
3. 加上雇主养老23.81%；
4. 加上INAIL保险，单列一行；
5. 加上其他雇主缴费（工资服务商列出的）；
6. 加上TFR和CCNL规定的基金；
7. 和用人部门的预算对比。

从第一步到第七步的差距，就是财务需要看到的数字。
